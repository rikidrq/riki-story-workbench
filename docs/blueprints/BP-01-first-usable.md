# BP-01 · 第一版可用闭环

## 输入

驾驶员于 2026-08-21 重开的第一版合同、Tavern Helper 4.8.19 固定声明、旧 `Riki剧情助手 2.2.0` 非数据库源码与发布包的只读复用证据、TavernWeave A0/A5/B1/B2/C1/C2/C3/C9/C10/C11/C12/C13/D3/D7。

## 输出

- 版本化运行 bundle。
- 可导入 Tavern Helper 的 CDN/本地加载器。
- 世界书库存、条目选择、受控修改、冲突检测、写后重读和撤销。
- 酒馆当前连接、Connection Manager profile、独立 OpenAI-compatible API，多套 API/System 预设和模块覆盖。
- 主控、总纲、大章、小章、人物、格式编译 Agent；详细/粗略/懒人工作流。推进预设按用户最新决定剔除。
- 分支会话、消息编辑/删除/重 Roll/复制、流式显示/停止/后台继续。
- 正式成果提案、逐项确认、版本链、Diff、回收站、请求诊断、项目导入导出。
- Command Core 运行时 API、响应式全屏工作台、静态预览、测试和用户说明。

## 允许修改范围

仅 `riki-story-workbench/` 新项目目录。旧 Riki、Cortex、数据库、插件、角色卡和真实 SillyTavern 安装目录全部只读。

## 禁止事项

不安装、不触碰真实密钥、不调用付费 API、不写旧项目、不实现 Growth Tracks、不生成角色卡 JSON/PNG。不得引入数据库内核、数据库 Agent/模板/运行期、推进预设、灵感二创、生图或素材库。发布只允许创建新 `v1.2.0`，不得移动 `v1.0.0` 或 `v1.1.0`。

## 执行步骤

- P1：创建权威链、项目骨架和版本来源。
- P2：建立旧版非数据库功能迁移账本；实现项目状态、成果、分支会话、模型配置、宿主适配、世界书事务、历史和命令分发。
- P3：实现策划 Agent、主控路由、流式讨论、三种工作流、UI、响应式状态与生命周期清理；关闭故障使用 RF-002 处理后返回本步骤。
- P4：构建版本目录、加载器、组件 spec、预览服务器和文档。
- P5：验证所有退出条件并更新 NEXT。

## 退出条件

- `npm run verify` 通过。
- TavernWeave 权威链验证通过。
- component 模式产物验证通过且没有卡 JSON/PNG。
- 加载器日常只需改一个 `RIKI_VERSION` 常量。
- mock 覆盖三种模型连接描述、预设解析、模块覆盖、流式/停止、分支会话、提案/确认/版本/回收站、项目导入导出，以及世界书读取、成功提交、陈旧冲突和撤销。
- 静态预览覆盖桌面与 320/375/430px；320px 真实触摸 × 后根节点 computed display 为 none、遮罩不可见、R 入口可重开。
- 真实宿主未测边界明确列出。

## 失败回退

发生实现错误时只建立一条非持久问题支线，解决后返回当前步骤。宿主 API 无法静态确认时保留能力失败状态，不猜测私有 DOM 或旧 Lorebook API。

## 停止条件

需要外部安装/发布/密钥/付费调用；真实宿主与固定声明不兼容；或必须扩大 First Usable 才能继续。

## 下一道门
